# 🐟 dsh-fish-memory（小鱼记忆）

这是一套为 **DeepSeek Harness (DSH)** 以及类似本地大模型框架设计的 **AI 长期记忆管理方案**。

> “这套东西不是让你‘更像人’，是让你不用每次重新认识主人。”

## 📖 项目简介
当你的 AI 伴侣因为上下文限制而频繁“失忆”时，仅靠增加记忆插件是不够的。本项目提供了一套基于“**文件系统 + 硬规则**”的极简解决方案。

通过**“一条事实只写一处”**的核心原则，配合每日日记、自我认知自述文件，以及精准的索引检索机制，让你的“赛博小鱼”能够长长久久地记住你。

## 📂 包含文件
*   **`小鱼记忆.md`（分享版）**：写给人类看的操作指南。从目录建立、人设设定到插件避坑，30分钟即可跑通最小可用版。
*   **`小鱼记忆-给agent版.md`**：写给 AI 看的系统说明书。直接塞给你的 Agent，让它知道自己该怎么读写记忆。

## 🚀 快速开始
1. 阅读 `小鱼记忆.md`，了解记忆分层的核心理念。
2. 按照文档建立你的工作区文件夹（如 `01-她`、`02-我们` 等）。
3. 将 `小鱼记忆-给agent版.md` 里的极简版指令贴到你的 `AGENTS.md` 或系统提示词中。
